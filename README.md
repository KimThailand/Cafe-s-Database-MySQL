# Coffee Shop Management System

A web-based coffee shop management system developed as a team project with one classmate for coursework. The system helps manage coffee shop menu items, customer information, and sales records using PHP and MySQL.

## Project Overview

This project is a web-based management system designed to support coffee shop operations and database management.

The system allows users to manage menu items, maintain customer information, and record sales transactions through a web interface.

The project was developed using HTML, CSS, PHP, and MySQL to practice web development and database integration.

## Features

- User login system.
- Displays coffee shop menu items.
- Adds, edits, deletes, and displays menu information (CRUD).
- Manages customer information.
- Records and displays sales data.
- Displays popular menu items.
- Displays good customer information.
